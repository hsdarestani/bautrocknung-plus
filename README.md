# Bautrocknung Plus

Premium corporate website for Bautrocknung Plus GbR in Friedberg, Germany.

## Deployment

Static site, no build step. Connect this GitHub repository to Cloudflare Pages.

- Production branch: `main`
- Framework preset: `None`
- Build command: *(leave empty)*
- Build output directory: `/`

The site uses static HTML, CSS, and JavaScript. No backend or tracking services are installed. The incident report on the site opens the user's mail application with a prefilled request; it does not save or transmit data to a server.

## Before launch

Check all contact information and the legal notices with the business. The privacy notice has been adapted for static Cloudflare hosting and mailto-based contact. Confirm Cloudflare configuration, applicable policies, and image usage rights before replacing the current live website.

## Design

German-only corporate website. Deep navy / technical blue / ivory palette, Swiss editorial layout, responsive design, no decorative arrow buttons.
